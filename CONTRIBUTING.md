# Katkıda Bulunma

Hata bildirirken XenForo sürümünü, PHP sürümünü, kullanılan tarayıcıyı, hatalı metin örneğini ve beklenen öneriyi belirtin.

Kod katkılarında mevcut eklenti dizin yapısını koruyun. Değişikliklerin XenForo 2.3 ile uyumlu olduğundan ve JavaScript/PHP sözdizimi kontrollerinden geçtiğinden emin olun.

Pull Request açıklamasında değiştirilen davranışı ve test edilen örnekleri kısa şekilde belirtin.
