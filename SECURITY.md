# Güvenlik Politikası

Güvenlik açığı olduğunu düşündüğünüz bir durum için herkese açık Issue içinde istismar adımlarını veya hassas verileri paylaşmayın.

Rapor içinde XenForo sürümünü, PHP sürümünü, etkilenen eklenti sürümünü, sorunun etkisini ve mümkünse tekrar üretim adımlarını belirtin.

Genel işlev hataları ve yazım önerisi problemleri normal GitHub Issues üzerinden bildirilebilir.
